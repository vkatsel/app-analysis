# Mobile App Subscription & Unit Economics Analysis

## Огляд проєкту
Цей проєкт присвячений аналізу монетизації та юніт-економіки мобільного додатка для вивчення мов. Основна мета — оцінити ефективність різних типів підписок, проаналізувати поведінку користувачів у розрізі географії та спрогнозувати життєву цінність клієнта (LTV) для оптимізації маркетингових витрат.

## Ключові бізнес-питання
1. Яка середня виручка на одного користувача (ARPU) та на одного платного користувача (ARPPU)?
2. Які країни є найбільш прибутковими та як розподіляється дохід за регіонами (Tiers)?
3. Який прогноз окупності маркетингових інвестицій на ключовому ринку (США) протягом року?
4. Як типи підписок впливають на рівень повернень (Refund Rate)?

## Методологія та інструменти
- **Data Processing:** Python (Pandas) для очищення даних, обробки часових рядів та розрахунку Net Revenue (з урахуванням податків, комісій сторів та рефондів).
- **Statistical Modeling:** SciPy для побудови логарифмічної регресії та прогнозування LTV.
- **Visualization:** Matplotlib для побудови кривих окупності та Tableau для інтерактивного дашборду.

## Основні результати аналізу

### 1. Метрики монетизації
* **Загальний ARPU:** $3.39.
* **Загальний ARPPU:** $7.72.
* **Лідируючий ринок:** США з чистим прибутком у $6057.65.
* **Найуспішніша когорта:** Лютий 2025 року згенерив $9874.02 чистого доходу.

### 2. Структура підписок та рефонди
* Найвищий рівень повернень (Refund Rate) спостерігається у річних підписок (**3.10%**), що може бути пов’язано з високим чеком та випадковими списаннями після тріалу.
* 73.46% користувачів обирають тижневу підписку, проте медіанна кількість оплат дорівнює 1.0, що вказує на необхідність покращення Retention.

### 3. Прогноз LTV та маркетинговий ліміт (США)
За допомогою логарифмічної регресії (MAPE моделі — 3.11%) було встановлено:
* **Прогнозований LTV (365 днів):** $5.19.
* **Target CAC:** Максимальна вартість залучення користувача не має перевищувати **$5.05**, щоб забезпечити прибутковість протягом року.
